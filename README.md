# WaterMeterCalculator

محاسبه‌گر فارسی و آفلاین کنتور آب برای اندروید.

- محاسبه درصد خطای کنتور
- محاسبه دبی بر اساس حجم و زمان
- محاسبه حجم آب عبوری بر اساس دبی و زمان

## ساخت APK
در تب Actions، گردش‌کار **Build Android APK** را اجرا کنید. پس از موفقیت، فایل **WaterMeterCalculator-APK** را از بخش Artifacts دانلود و از حالت ZIP خارج کنید. APK خروجی از نوع debug است و برای نصب آزمایشی مناسب است.

فرمول خطا: (حجم ثبت‌شده - حجم واقعی) / حجم واقعی × 100

فرمول دبی L/h: حجم لیتر × 3600 / زمان ثانیه
